# Traffic Light Recognition Website

## Run step by step
1. Extract the ZIP file.
2. Open the extracted folder in VS Code.
3. Open `index.html` in Chrome, or install the Live Server extension and click **Go Live**.
4. Upload a clear traffic-light image.
5. Click **Analyze image**.

No Python installation or server is required for this website.

## Files
- `index.html`: website structure
- `style.css`: design and responsive layout
- `script.js`: image upload and color detection

## Important
This is a simple color-based browser demo, not a trained AI model. It chooses the dominant red/yellow/green color across the whole image, so backgrounds can affect results. Do not use it for real driving or road-safety decisions.
